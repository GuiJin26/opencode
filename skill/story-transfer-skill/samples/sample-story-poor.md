# Order Cancellation

**Story ID:** ORD-482
**Author:** Business Team
**Priority:** High

## Story

As a customer, I want to cancel my order so that I don't receive items I no longer need.

## Description

The customer goes to My Orders and clicks Cancel on the order. The order gets cancelled and the money comes back to them. The system should be fast and user-friendly. It should also handle invalid input appropriately.

For reporting, the cancellation should be tracked somewhere.

## Notes

- We need this by end of sprint, it's urgent.
- The cancellation should work smoothly for all orders.
- Please make sure validation works correctly.
